fix: auto-read unsubmitted AI original questions on re-entry (#168)

Closes #168.

## Summary
- Track accepted MAIN answer submissions separately from editable draft text, per survey node.
- Auto-read an unsubmitted AI original question once on each eligible navigation presentation, even if a draft exists.
- Prevent editing or clearing draft text from independently triggering original-question playback.
- Preserve follow-up priority and existing TTS readiness, lifecycle, navigation ownership, and suppression guards.

## Root cause
The MAIN composer persists draft text to `SurveyViewModel.answers` before Send. Original-question auto-read incorrectly used `originalAnswer.isBlank()` as a proxy for whether the user submitted an answer. A nonempty unsent draft suppressed playback; clearing the draft made the question eligible again without navigation.
