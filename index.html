What's New

feat(slm): enable safe cross-survey reuse and TTS readiness caching

## Summary

Enable safe cross-survey LiteRT-LM GPU Engine reuse by default and reuse successful TTS readiness checks across survey sessions.

The goal is to eliminate unnecessary model reinitialization and transient loading spinners while preserving independent survey sessions and safe runtime ownership.

## Changes

- Enable cross-survey SLM runtime reuse by default in normal Debug and Release builds, with `-Pslm.crossSurveyReuse=false` available as an explicit opt-out.
- Preserve compatible GPU Engine instances across survey sessions while releasing survey-specific Conversation state.
- Add runtime generation, ownership, cancellation, and replacement-boundary safeguards.
- Reset survey progress and transient state when returning Home and starting a new survey.
- Preserve existing Back/Next navigation behavior.
- Cache only successful TTS readiness checks, keyed by effective engine, language, offline-voice requirement, and required-engine policy.
- Invalidate affected TTS readiness results on package changes, relevant playback failures, and voice-data changes.
- Add deterministic regression tests for SLM lifecycle, survey reset, initialization UI, and TTS cache concurrency/invalidation.
