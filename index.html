What's New

Disable blank GitHub issues

## Summary

Disable GitHub's default **Blank issue** option.

After this change, new issues should use one of the configured templates:

- Bug Report
- Engineering Issue

## Change

Add:

- `.github/ISSUE_TEMPLATE/config.yml`

with:

```yaml
blank_issues_enabled: false
```

## Scope

No application code, tests, workflows, survey configuration, or existing Issue Templates are changed.
