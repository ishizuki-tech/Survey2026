What's New

Protect production diagnostic content

## Summary

- add an explicit `-Pdiagnostics.production=true|false` policy independent of build type, CI, upload routing, signing, or secrets
- preserve full diagnostics for Debug, local Release, Branch Build, and normal GitHub Actions Release validation builds
- redact respondent-derived transcript, prompt, model-response, follow-up, and error-message content only for explicitly marked Production builds
- add final trace-boundary protection for Survey/Whisper diagnostics
- keep safe metadata such as IDs, lengths, status, score, exception class, and stack frames
- prevent Production persistence through runtime, ring, crash, direct logcat, and AiTrace payload paths
