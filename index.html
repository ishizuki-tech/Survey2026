## Summary

Closes #120 (after validation and merge).

Implement trusted model integrity validation for Gemma 3n E4B LiteRT-LM int4 across manual selection, download, local reuse, and persistent storage.

### Changes

- Pin the official Gemma model to an immutable Hugging Face revision.
- Enforce the official file size and SHA-256.
- Validate model artifacts before atomic promotion.
- Reject invalid manual selections while preserving previously verified models.
- Validate normal, resumed, parallel, and HTTP 416 download completion.
- Invalidate corrupted resumable transfer state safely.
- Validate existing private/cache files and MediaStore restoration.
- Verify pending MediaStore contents before publication.
- Preserve verified model bytes during native runtime failures.
- Retain Issue #123 ownership, cancellation, and atomic replacement guarantees.
- Add deterministic regression tests.
