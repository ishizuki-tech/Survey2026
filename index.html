## Summary

Selectively ports voice-first and AI interaction UI improvements from Frank's `feature/ui-updates` branch onto current `main`.

This is PR 2 of the two-part UI migration, following PR #145.

## Changes

- Introduces a voice-first answer composer with `Type instead`.
- Supports transcript review, editing, and re-recording.
- Adds an elapsed recording timer and full-screen Stop UI.
- Adds current follow-up replay and conditional automatic TTS.
- Prevents unintended autoplay of restored follow-up questions.
- Reuses the primary-action styling introduced in PR #145.
- Preserves existing pinned-to-bottom conversation scrolling and jump controls.
