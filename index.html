What's New

Preserve completed surveys when upload is unavailable

## Summary

Closes #62.

This PR updates the Review -> Finish flow so a completed survey can finish safely even when upload configuration is unavailable.

When upload configuration is missing, the survey is now staged in the existing pending-upload storage, the app proceeds to Done, and the user can start a new survey while the completed survey remains available for later recovery/upload.

## Changes

- remove the Review-path Activity exit when upload configuration is unavailable
- allow finalization with nullable upload configuration
- add an explicit locally-pending finalization result/state
- stage or reuse the canonical pending survey JSON when upload config is absent
- skip GitHub reconciliation, WorkManager enqueueing, and upload-artifact scheduling in the no-config path
- advance Review -> Done for both queued uploads and locally staged pending surveys
- preserve existing already-uploaded precedence so an uploaded survey is not recreated as pending
- preserve duplicate-Finish protection and existing configured-upload behavior
